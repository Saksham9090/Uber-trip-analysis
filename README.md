# Uber Trip Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes Uber trip data to identify:
- Peak booking hours
- Trip distance trends
- Revenue insights
- Customer behavior
- Ride demand patterns

## Tools Used
- Power BI
- Excel / CSV
- Data Cleaning
- Data Visualization

## Dashboard Features
- Interactive filters
- KPI cards
- Trend analysis
- Location-wise insights
